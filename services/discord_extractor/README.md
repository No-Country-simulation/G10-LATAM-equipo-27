# Discord Extractor

Servicio de ingesta: expone una API REST (FastAPI) que lee mensajes de canales de Discord
mediante un bot propio, los transforma al formato de interacciones de CommunityLab y guarda
el paquete resultante como un objeto JSON en **OCI Object Storage** (capa Always Free).
